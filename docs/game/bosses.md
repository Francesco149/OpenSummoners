read it from memory in rhost (actor struct; `docs/ods-crossref.md` Actor Format) if needed. [DK] boss list:

first [DK][ZO]; save at the fountain/statue that precedes almost every boss [DK].

Notes for agents

  (save prompt before interlude) [DK].
