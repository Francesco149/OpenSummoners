# Walkthrough — ordered route (EN-old)

Spine = **[DK]** (complete), cross-checked with **[ZO]** (to Day 8), area names per **[EXE]**. Paraphrased.
Each step: what to do next. 🔑 = progress-required. 💎 = optional loot worth taking (Marks of Heroism are
optional but raise level cap — take all 20). ⚠ = trap / danger. "MoH n" = n-th Mark of Heroism.
Stuck? Main Menu → `Messages` gives the day's hint [DK].

World layout (rough): Tonkiness (start). East (right) exit → fields → Minasa-Ratis Magic School → further
east → Mountain Cave. West (left) exits → Shrine of the Wind (via residential street), bridge → Barness
road / Weathervane Tower road / Loch Carudale → Chartreux City (far west, across lake) → north: Flower
field / caves → North Chartreux Guardpost → Archmage's Tower. School east road (Day 8) → Org Lair →
Cranbal Valley → Korat Village. [DK][ZO][MAP]
